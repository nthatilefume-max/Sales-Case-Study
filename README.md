

This project is an end-to-end sales analytics solution developed using **Excel, SQL, and Power BI** to analyze FNB sales performance and support data-driven decision-making. The dataset was cleaned and transformed using SQL, where key metrics such as **Average Unit Price, Gross Profit, Gross Profit Percentage, and Profit per Unit** were calculated. The analysis focused on identifying sales trends, measuring profitability, and evaluating overall business performance through structured SQL queries.

The final output is an interactive Power BI dashboard that presents key performance indicators (KPIs), sales trends, profitability analysis, and dynamic filters for deeper exploration of the data. This project demonstrates my skills in **data cleaning, SQL querying, data transformation, business intelligence, and dashboard development**, showcasing my ability to turn raw data into meaningful insights and actionable business recommendations.
